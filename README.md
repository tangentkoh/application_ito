# application_ito

### 「ito」をWebアプリとして実装したい！

カードゲーム「ito」をWebアプリとして実装をしたい。

概要
主にスマートフォンで動かすことを目的とする。デプロイ自体はGithubPagesで行い、
QRコードやリンクで表示できるようにする。
使用言語はhtml、css、Javascriptのみ、
ファイル名は"index.html"、"style.css"、"main.js"とする。

内容
・1から100のうち、ランダムな数字を出力する機能。これは、画面上のボタンにより、
何度でも抽選できる。ただし、誤操作防止のため、後述するブラインド機能を、一度
利用しなければ、再抽選はできない。（一度ブラインドして、それを解除すると、
抽選ができるようになる）なお、操作回数に関わらず、ブラインド中は再抽選不可。
・ブラインド機能。実際にはお互いに画面を見せ合いながら遊ぶことを想定している
ため、画面上のボタンにより、数字を見えないようにできる。
・テキスト入力、表示機能。これにより、自身の数字に対する回答を表示しておく。
ゲーム中で自身の意見を忘れるのを防止したり、途中で更新もできるようにしたり、
お題を書き込んでおいたりするためである。なお、テキストはブラインドしない。
・アニメーション。CSSを利用して、簡易的なアニメーションをつけ、完成度を高める。
ただし、過度な装飾は控えること。

UI
画面最上部にタイトル「itoアプリ」
中央部に数字
中央左側に抽選ボタン
中央右側にブラインドボタン
画面下部にテキスト表示エリア（クリック/タップで入力/編集可能）
背景は暗めの藍色

実装内容のまとめ

抽選ボタン	1〜100のランダムな数字を表示、ポップアニメーション付き
ブラインドボタン	カードが3Dフリップして数字を隠す。解除すると「解除」→「ブラインド」に戻る
再抽選制限	抽選後はブラインド→解除のサイクルを完了しないと再抽選不可。ブラインド中も不可
メモエリア	タップで編集モード（textarea）、ブラー/Escで表示モードに戻る。ブラインドの影響なし
アニメーション	数字のポップイン、カードの3Dフリップ、ボタンのプレス縮小、ホバーグロー
デザイン	暗めの藍色背景、ラジアルグラデーション、スマートフォン向けレイアウト
